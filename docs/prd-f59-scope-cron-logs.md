# PRD F-59：工作台作用域化（定时任务 / 运行日志跟随当前项目）

> 状态：已实施回填 v1 · 2026-11-09 · 依赖 F-22（cron 存储）、F-41（运行日志）、F-58b（委派式工作台）
> 背景：F-58b 改版评审中用户指出「左侧第一个菜单管项目会话，后面几个菜单管不到」——定时任务与运行日志是全局页面，与左侧选中的项目完全脱节。本文档将其作用域化。
> 实施记录：与本文档同批的 feat(web) 提交，2026-11-09。

## 1. 变更目标

1. **G1 上下文一致**：定时任务、运行日志两个子路由页默认跟随左侧当前选中的项目展示，消除「切了项目但右边页面无感」的割裂。
2. **G2 可回退**：作用域是默认视图而非硬过滤——每页提供一键切「全部」，全局数据一眼可达。
3. **G3 零协议变更**：cron.json 任务自带 `cwd`（F-22 §3）、LogEntry 自带 `sessionId`（F-41 D10，明确标注「Web 过滤用」）——归属过滤在 Web 端完成，不改 core 存储、不加端点。

## 2. 需求（P0 已全部实施）

- **定时任务页（/cron）**：新增作用域开关（列表区首个 chip，激活态显示「📁 项目名」）——默认只显示 `cwd` 等于当前项目根或位于其子目录内的任务；关闭后显示全部项目。Tab 计数（全部/已启用/已暂停）基于作用域后的集合，数字与所见一致。空态区分「当前项目暂无（提示切全部）」与「全局暂无」。
- **运行日志页（/logs）**：新增作用域开关（头部按钮）——默认只显示 `sessionId` 命中当前项目会话集合的条目；无 `sessionId` 的 serve/cron 级全局条目在作用域下隐藏。级别计数 chip 同样基于作用域后集合。项目会话集合进入页面 / 切项目时一次性拉取（`limit=500`，环形缓冲仅 1000 条，覆盖足够）。
- **纯函数抽取**：`utils/scope.ts`（`cwdInRoot` / `logEntryInProject`）+ 单测 9 例（含 `/project-x` 兄弟目录前缀陷阱、root 尾斜杠、空集合等边界）。

## 3. 交互要点

1. 未选中项目时两页自动展示全部（作用域开关隐藏，不出现空转开关）。
2. 作用域开关 hover 提示说明当前过滤口径与切换动作；项目名超长省略号截断（220px）。
3. 切换项目（左侧点击）后两个页面的过滤集合即时跟随（computed 依赖 `ws.activeProjectId`；日志页会话集合 watch 重拉）。
4. 批量管理 / 启停 / 立即运行等既有操作不受作用域影响（按 id 操作，作用域只影响可见集）。

## 4. 验收标准

1. 选中项目 A 时，/cron 只显示 cwd 在 A 根内的任务，三个 Tab 计数一致；切「全部项目」恢复全量。
2. cwd 为 `/a/b` 的任务不会因项目根 `/a/b-c` 的前缀相似而误入（scope.test.ts 覆盖）。
3. 选中项目 A 时，/logs 只显示 A 的会话条目，级别计数一致；serve/cron 全局条目被隐藏；切「全部日志」恢复。
4. 未选项目时两页展示全量且不渲染作用域开关。
5. 既有门禁全绿（typecheck / web 单测含新增 9 例 / smoke:web / web e2e）。

## 5. 已知限制与待确认

1. **日志会话映射按需拉取**：项目会话 > 500 条时旧会话日志在作用域下可能漏显（切「全部日志」可看）；如需严格完备，后续在 core 提供 session→project 映射端点。
2. **cron 归属以 cwd 字面匹配为准**：项目注册后若目录被移动/改名，旧任务 cwd 不再命中（显示「当前项目暂无」），需在任务编辑里更新 cwd——保持 F-22「cwd 是任务属性」语义不变。
3. 文件面板 / 终端 / 任务台本就跟随项目/会话，不在本期范围。
