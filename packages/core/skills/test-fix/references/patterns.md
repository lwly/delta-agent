# 测试失败定位模式库

## 模式 1：批量类型错误
现象：tsc 报大量 TS2304/TS2305。
处置：从第一个错误开始修（后续错误多为连锁）；通常是导入路径或导出遗漏。

## 模式 2：仅 CI 失败、本地通过
排查顺序：Node 版本差异 → 平台差异（路径分隔符、行尾 CRLF）→ 环境变量缺失 → 时区相关的日期断言。

## 模式 3：间歇性失败
排查顺序：竞态（未 await 的异步）→ 测试间共享状态未清理 → 端口/文件锁冲突 → 浮点精度。
工具：缩小并发（--pool=forks）、单独重跑定位。

## 模式 4：快照不匹配
先判断输出变化是否为预期行为：是则 `vitest -u` 更新并说明理由；否则查真实回归。

## 修复纪律
- 每个 fix 单独可验证，不做顺手重构
- 修复后必须全量回归，不只跑单个文件
