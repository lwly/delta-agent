# Commit 审查检查清单

## 阻塞项（发现即阻止提交）
- [ ] 硬编码密钥 / API Key / 密码 / 内网地址
- [ ] 调试代码残留（console.log、debugger、print 调试输出）
- [ ] 注释掉的死代码块（应删除而非注释）
- [ ] 未处理的 Promise / 异常吞没（空 catch）

## 安全项
- [ ] 用户输入直接拼接进命令 / SQL / 路径
- [ ] 路径参数未做沙盒边界校验（逃逸 projectRoot）
- [ ] 敏感信息写入日志或错误消息

## 质量项
- [ ] 新函数缺少必要测试
- [ ] 命名与项目惯例不一致
- [ ] 公共接口变更未同步文档 / 类型定义

## Commit message 规范
- type(scope): 摘要，摘要不超过 50 字，祈使句
- 正文列变更点，每行不超过 72 字
- 破坏性变更必须以 `!` 或 `BREAKING CHANGE:` 标注
